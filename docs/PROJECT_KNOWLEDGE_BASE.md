# Project Knowledge Base

This document is the baseline context for humans and AI agents working on this
repository. Keep it updated when the project changes architecture, fiscal
behavior, provider integrations, database schema, configuration, or operational
flow. For each change, there must be a one-paragraph summary explaining why the
change was needed and how it was implemented. Link it to the corresponding
specification in the `specs` folder, when it exists.

For development practice, testing discipline, and gradual architecture
evolution, use `docs/DEVELOPMENT_REGIMENT.md` together with this knowledge base.
